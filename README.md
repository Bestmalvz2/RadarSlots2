# Radar de Slots

Aplicativo Android experimental para registrar informações visíveis durante sessões de slots, com captura de tela autorizada pelo Android e reconhecimento de texto (OCR).

## Objetivo do MVP
- Solicitar autorização explícita para captura de tela usando MediaProjection.
- Reconhecer textos visíveis relacionados aos jogos Big Bass Bonanza e Big Bass Splash.
- Registrar ocorrências textuais como SCATTER, BONUS e FREE SPINS para consulta posterior.

## Limitações importantes
Este projeto é experimental. OCR pode falhar, não reconhece de forma confiável símbolos gráficos nem posições de rolos, e não determina quando um bônus está próximo. Resultados de slots dependem de RNG; o aplicativo não prevê resultados nem garante ganhos.

## Estado
